# Module 1 - Python & Data Science Fundamentals

## Overview
This repository contains my work for **Module 1: Python & Data Science Fundamentals**.

The goal of this module is to build a foundation in Python programming and understand how Python can be used for basic Data Science tasks.

## Topics Covered
- Python setup using Google Colab/Jupyter Notebook
- Variables and data types
- Conditional statements
- For and while loops
- Functions
- Lists and dictionaries
- File handling
- Introduction to Data Science
- Basic data analysis using Pandas
- Mini project: Student Performance Analysis

## Mini Project
### Student Performance Analysis
The mini project uses a small student dataset to calculate:
- Subject averages
- Overall class averages
- Top-performing student
- Students with high attendance
- Students whose average score is 80 or above

## How to Run
1. Open the `.py` files in Python, VS Code, Jupyter Notebook, or Google Colab.
2. Run each program and observe the output.
3. For the Data Science examples, install Pandas if required:
```bash
pip install pandas
```

After completing this module, I gained practical understanding of Python fundamentals and basic data analysis concepts. I also learned how to organize programming work in GitHub and apply Python to a simple real-world style dataset.
